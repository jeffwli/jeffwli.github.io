Place publication images and MP4 videos in this folder.
Suggested filenames:
- centerless-quadrotor.mp4
- shell-gripper.mp4
- reconfigurable-inflatables.jpg

Then set the corresponding media entry in data/publications.js, for example:
media: {
  type: "video",
  src: "assets/media/centerless-quadrotor.mp4",
  poster: "assets/media/centerless-quadrotor-poster.jpg",
  alt: "Center-less quadrotor grasping and carrying a payload"
}
